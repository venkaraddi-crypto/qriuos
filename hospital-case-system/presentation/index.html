LLM drafts Subjective / Objective / Assessment / Plan

One click — the doctor remains the signer of record

Pre-consult intake (patient, at home): consent-gated adaptive questions — the branching engine scores complaint keywords and asks only what matters (cardiac ≠ dermatology).

In the room (doctor): ambient scribe records the conversation, separates the two speakers, drafts the note; vitals trend and prior visits are one glance away.

Paper → digital: patients photograph old lab reports / prescriptions; OCR + extraction recovers values, flags abnormals against reference ranges, and the doctor confirms.

Only if both fail. Response is flagged mocked:true with the real error attached. Never fabricates text.

  • Tested honesty: the suite includes an explicit assertion that when no engine can transcribe, the API returns provider:"none" + error — not a made-up transcript
  • Admin transparency: a live real-vs-mocked table on the admin portal shows exactly which capabilities are live

10 · Privacy is the product

Encrypted, consented, audited —
and the audio deletes itself.

AES · Fernet

Aadhaar numbers encrypted at rest, masked XXXX-XXXX-1234 in every API response. Medical Drive blobs stored encrypted, never publicly served.

Rotating sessions

Short-lived JWT + httpOnly refresh cookie that rotates on every use; patients can see and revoke all active sessions.

Granular consent

Consultation recording requires explicit per-item consent, is revocable, and raw audio auto-purges after the retention window (default 30 days).

Audit & ownership

Every sensitive action logged; patients can read only their own records (403-tested), staff act only within their role.

Production mode refuses to boot with a development secret or missing encryption key · drug-interaction pair list guards prescriptions · access to another patient's Drive documents requires an explicit, expiring, reason-tagged grant

13 · Real-world impact

Where this goes next — the point
of the whole exercise.

Primary Health Centres

A typical PHC doctor sees 100+ patients a day with no digital record. ArogyaSetu turns each visit into structured, coded, FHIR-exportable data — feeding ABHA, not plastic bags.

Ayushman Arogya Mandirs

India's 1.5+ lakh Ayush health & wellness centres deliver integrative care that no EHR represents today. Dual-coded records make AYUSH outcomes measurable nationally.

Continuity of care

A migrant worker treated in Bengaluru walks into a PHC in Bihar; the case file, allergies and medicines follow the ABHA account, not the paper.

Public-health signal
